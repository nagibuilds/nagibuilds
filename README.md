# Nagi Builds

Webアプリと、AIを使った業務ツールを作っています。画面や機能だけでなく、権限の分け方、実行記録、引き継ぎまで含めて設計することを重視しています。

## 取り組んでいること

- Webアプリ・管理画面の設計と実装
- AIを組み込んだ業務フローの試作と検証
- 既存システムの調査、改善、運用手順の整理

このアカウントでは、公開できるサンプルと再現手順を順に置いていきます。制作中のものや顧客のコードを、実績として先回りして公開することはしません。

依頼案件は公開用のリポジトリと分けます。対象と権限を確認したうえで、依頼主の非公開リポジトリに招待していただく形を想定しています。
